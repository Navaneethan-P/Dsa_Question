# LeetCode Java DSA Prep Dashboard

## About
The **LeetCode Java DSA Prep Dashboard** is an interactive, frontend-only application designed to help you prepare for software engineering interviews. It acts as a comprehensive library for the Top 150 LeetCode problems, categorized by topic. 

The application offers:
- **Optimal & Brute Force Java Solutions:** Clean, copy-pasteable code blocks for standard interview answers.
- **Interactive Array Visualizer:** An animated visualizer that dynamically traces step-by-step algorithms, supporting Standard Array iteration, Two-Pointer collisions, and Sliding Windows.
- **Algorithm Walkthroughs & Memory Traces:** A step-by-step breakdown of how the logic flows in memory.
- **Topic-Wise Active Recall Q&A:** A dedicated section that tests your fundamental knowledge of the current topic (e.g., Arrays, HashMaps, Two Pointers).
- **Progress Tracking:** Locally stores your solved problems and shows a visual completion circle.

## Instructions to Use

Since this is a lightweight, dependency-free static web application, there are no complicated installation steps, build tools, or local servers required.

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/Navaneethan-P/Dsa_Question.git
   ```
2. **Open the App:**
   Simply locate the `index.html` file in the project folder and double-click it to open it in your default web browser. 
   *(Alternatively, right-click `index.html` and select "Open With" -> Chrome / Safari / Edge / Firefox).*
3. **Using the Dashboard:**
   - **Sidebar Filter:** Use the search bar or the topic chips (e.g., Arrays, Two Pointers) to narrow down the problem list.
   - **Interactive Visualizer:** In the **Overview** tab, click "Play" on the Interactive Array Visualizer to see an animated step-by-step breakdown of the algorithm.
   - **Mark as Solved:** Check off problems as you solve them. Your progress is saved automatically to your browser's local storage.
