# Java DSA Prep Dashboard

## About
The **Java DSA Prep Dashboard** is an interactive, frontend-only application designed to help you prepare for software engineering interviews. It acts as a comprehensive library for top interview problems, categorized by topic.

The application offers:
- **Optimal & Brute Force Java Solutions:** Clean code blocks for standard interview answers.
- **Interactive Array Visualizer:** An animated visualizer that dynamically traces step-by-step algorithms, supporting standard array iterations, two-pointers, and sliding windows.
- **Algorithm Walkthroughs:** A step-by-step breakdown of how the logic flows in memory.
- **Topic-Wise Active Recall Q&A:** A dedicated section testing fundamental knowledge.
- **Progress Tracking:** Locally stores your solved problems and displays completion progress.

## Instructions to Use

Since this is a lightweight, dependency-free static web application, there are no complicated installation steps, build tools, or local servers required.

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/Navaneethan-P/Dsa_Question.git
   ```

2. **Open the App:**
   Simply locate the `index.html` file in the project folder and double-click it to open it in your default web browser.

3. **Using the Dashboard:**
   - **Sidebar Filter:** Use the search bar or the topic chips to narrow down the problem list.
   - **Interactive Visualizer:** In the **Overview** tab, click "Play" on the Interactive Array Visualizer to see an animated breakdown of the algorithm.
   - **Mark as Solved:** Check off problems as you solve them. Your progress is saved automatically to your browser's local storage.
